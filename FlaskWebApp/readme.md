
# FLASK WEB FRAMEWORK

## INTRODUCTION

Flask is a microframework used to build we applications. It helps the frontend and backend comminicate with each other by acting as an Application Programming Interface for them. It is a lightwieght, minimal and syntactically simple framework that is easy to learn and implement. 

## FOLDER STRUCTURE



```
└──FlaskWebApp                                      # Flask webapp boilerplate 
│   └── readme.md                                   # Brief introduction to flask as well as project details
    └── make_flaskapp_directorystructure.sh         # Bash script to instantly create the entire boilerplate
    └── write_contents.sh                           # Bash script to write the contents of the files in the project
```

## STEPS TO USE BOILERPLATE

- Download both the bash scripts and put them inside the folder where you want to create the project. 

- This is your root directory. Run 'make_flaskapp_directorystructure.sh' to create the directory structure.

- Run 'write_contents.sh' to write the contents of the files in the project.


## USES

* Flask, by default, launches the web app on the localhost server on port 5000.

* However, Flask can also be used to launch the web app on a live server.

## DEPENDENCIES

pip install flask
