# Developer Boilerplates

A collection of lightweight, production-ready project templates and initialization scripts to skip repetitive setup tasks. This repository contains boilerplates, templates and examples for common uses of various programming languages, frameworks and tools.

Every Sub-folder in this repository has its own readme.md file to explain the content, usecase and limitations in detail. It is highly advised to go over the appropiate readme.md files before running the scripts. 


## 📂 Repository Structure


```
BOILERPLATES
└── readme.md                                       # Introductory README.md file
└── Assets                                          # Folder containing .png, .jpg, .svg files (if any)
└──FlaskWebApp                                      # Flask webapp boilerplate 
    └── readme.md                                   # Brief introduction to flask as well as project details
    └── make_flaskapp_directorystructure.sh         # Bash script to instantly create the entire boilerplate
    └── write_contents.sh                           # Bash script to write the contents of the files in the project
```
