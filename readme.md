# BOILERPLATES

This repository contains boilerplates, templates and examples for common uses of various programming languages, frameworks and tools. I made this repository to help me and others to get get started with new projects, skipping the repetetive tasks of setting up a new project from scratch every time.

## Folder Structure

```
BOILERPLATES
└── readme.md                                       # Introductory README.md file
└── Assets                                          # Folder containing .png, .jpg, .svg files (if any)
└──FlaskWebApp                                      # Flask webapp boilerplate 
│   └── readme.md                                   # Brief introduction to flask as well as project details
    └── make_flaskapp_directorystructure.sh         # Bash script to instantly create the entire boilerplate
    └── write_contents.sh                           # Bash script to write the contents of the files in the project
```
